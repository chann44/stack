# Stack Data Structure

A stack is an abstract data structure that stores elements in the order they are added. Elements are inserted and removed from the same end, known as the **top of the stack**.

A stack follows the **Last In, First Out (LIFO)** principle, meaning the last element added is the first one to be removed.

## Core Operations

1. **Push** — Adds an element to the top of the stack.
2. **Pop** — Removes and returns the top element of the stack.
3. **Peek** — Returns the top element without removing it.
